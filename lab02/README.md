
## Редактор карты местности
**Паттерн проектирования:** Приспособленец (Flyweight)  
## 1. Описание предметной области
Редактор карты  — это графическое приложение , позволяющее пользователю создавать и редактировать карту на основе сетки тайлов. Пользователь выбирает тип тайла из палитры и размещает его на полотне, формируя карту с различными типами местности.

## 2. Описание проблемы

При наивной реализации каждая ячейка карты является самостоятельным объектом, хранящим полный набор данных: тип местности, текстуру, цвет. Однако большинство ячеек визуально и логически идентичны — тысячи ячеек «Трава» хранят абсолютно одинаковые данные.

Это порождает три взаимосвязанные проблемы:

- Избыточный расход памяти — карта 36×24 = 864 ячейки, каждая дублирует одинаковые данные тайла.
- Снижение производительности — при отрисовке каждый объект обрабатывается независимо, хотя большинство из них визуально одинаковы.
- Плохая масштабируемость — при увеличении карты количество объектов растёт пропорционально, хотя уникальных типов остаётся всего 6.

## 3. Решение с помощью паттерна Приспособленец

Паттерн Flyweight решает проблему за счёт разделения состояния объекта на две части.

| Внутреннее состояние (intrinsic) | Внешнее состояние (extrinsic) |
|---|---|
| Тип тайла (трава, вода, камень…) | Координата X ячейки на карте |
| Текстура (QPixmap) или цвет тайла | Координата Y ячейки на карте |
| Название тайла (QString) | Размер ячейки (cellSize) |

Внутреннее состояние неизменно и разделяется между всеми ячейками одного типа — оно хранится в единственном объекте ITileType. Внешнее состояние уникально для каждой ячейки и передаётся при вызове метода draw().

Таким образом, вместо 864 полноценных объектов система оперирует лишь 6 объектами типов тайлов, а каждая ячейка хранит только координаты и указатель на нужный тип.

## 5. Сравнение потребления памяти

Замер проводился при одинаковом количестве размещённых тайлов — 864 ячейки (карта заполнена полностью).

| Объектов-типов в памяти | 864 | 6 |
| Потребление памяти тайлами | 960.2 КБ | 13.5 КБ |
| Экономия памяти | — | ~71× |

## 6. Вывод

Внедрение паттерна Приспособленец позволило кардинально сократить потребление памяти приложением. При полностью заполненной карте из 864 ячеек версия без паттерна потребляла 960.2 КБ, тогда как версия с паттерном — всего 13.5 КБ.
Ключевым фактором экономии является то, что тяжёлые данные — текстуры и цвета — хранятся в единственном экземпляре каждого типа тайла внутри TileTypeFactory, а все 864 ячейки карты содержат лишь координаты и лёгкий указатель на общий объект. Сколько бы тайлов одного типа пользователь ни разместил — в памяти по-прежнему остаётся ровно 6 объектов-приспособленцев.
Таким образом, паттерн Приспособленец показал себя эффективным решением для задач где в программе создаётся большое количество однотипных объектов с повторяющимися данными.
